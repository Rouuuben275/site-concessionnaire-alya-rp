## 🚀 Lancement

```bash
npm install
npm run dev
```

L'application démarre sur **http://localhost:5173**

## 📦 Deployment Netlify

```bash
npm run build
```

Ensuite, uploadez le dossier `dist/` sur Netlify ou connectez votre repo GitHub à Netlify.
